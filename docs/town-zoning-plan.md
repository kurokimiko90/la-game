# 小鎮分區規劃：戶外一整片、室內集中成一個大區塊

> 日期：2026-09-23｜狀態：**已實作**（`feat/scene-staging`，還沒合併）；室內區放南邊、有進出建築按鈕

## 問題

每個自動生成的街區是 2×2 的四宮格，戶外和室內混著放（例如醫院：左上是門口的馬路，其他三格是室內）。整張地圖看起來像一塊塊拼布：馬路走到一半接一間沒有屋頂的房間，房間旁邊又是一段馬路，不像一座真的小鎮。

現況：13 個場景共 52 個區域，其中戶外 24 個（手畫 12 + 生成 12），室內 28 個（超市 4 + 生成 24）。

## 做法：同一張地圖，北邊是戶外街景，南邊是室內剖面區

```
 x: 0                     3600                                  8800
 ┌──────── 公園 ────────┬河┬──────── 東區街景（戶外地塊）────────┐ y 0
 │ 入口 廣場 遊樂場 湖  │  │ [餐廳門口][露天甜點][郵局門口][消防局前院]│
 │══ 商業街 ════════════│  │════════════ 東西向大街 ═══════════════│
 │ 超市門面（純背景）   │  │ [學校門口][操場][醫院門口][圖書館門口] │
 │ [車站前廣場][月台]   │  │════════════ 東西向大街 ═══════════════│
 │ [機場入口]           │  │ [麵包店門口] [空地塊…]                 │
 ├──────────────────────┴──┴────────────────────────────────────────┤ y ≈ 3900
 │                        室內剖面區                                 │
 │ ┌ 超市（4 區，手畫）┐   ┌ 醫院：大廳 │ 候診區 │ 藥局 ┐           │
 │ ┌ 車站：售票大廳 │ 剪票口 ┐  ┌ 機場：報到 │ 安檢 │ 候機 ┐       │
 │ ┌ 餐廳：用餐區 │ 廚房 ┐   ┌ 學校：教室 │ 圖書室 ┐               │
 │ …每棟建築的房間排成一列，外牆 + 內門，建築之間是走廊              │
 └──────────────────────────────────────────────────────────────────┘ y ≈ 7600
```

- **戶外區**：手畫的公園、商業街、河邊原地不動。生成街區的戶外區域改成沿街排列的「地塊」（1300×650），每塊面向大街，後側畫建築門面和入口。原本超市那塊（0–2600 × 1640–2600）改成超市門面加 2 個地塊。
- **室內區**：每棟建築的室內房間排成一列（2–3 間，每間 1300×650），畫外牆、房間之間的門、建築之間的走廊；每棟上緣用小地圖的顏色標示（不放文字）。超市整塊搬進來，形狀不變。
- **進出建築**：場景的戶外門口和室內房間分在兩處。畫面上加「進入室內 / 回到戶外」按鈕（UI 層，不是地圖物件），一鍵把鏡頭移到同一個場景的另一部分。

**為什麼選這個**：還是同一張地圖，程式裡「一個場景 = 幾個區域矩形」的模型不用改；物件位置可以整區平移，不用重排。

## 關鍵：搬區域用平移，不重排

物件位置都在區域內。區域搬家時，把鎖定檔裡這個區域的物件整批加上位移（dx, dy）就好，區域內的相對位置完全不變。

- 生成街區：情境檔是相對座標，家具也跟著算出來，不用 `--reset`。
- 超市：鎖定檔平移，`WorldBackground` 的超市地形包一層 `translate`。
- 公園、商業街、河邊：不動。

## 容量

- 戶外：東區 4 欄 × 4 列 = 16 塊，加上舊超市位置 2 塊，共 18 塊；目前用 12 塊。
- 室內：寬 8800，每列放 2 棟 3 房的建築，目前 8 棟加超市約 5 列（高約 3700）。
- 自動擴展還有 21 個主題（上限 30 個場景），全做完大約還要 25 個地塊、21 棟建築。配置器依序往東、往南長，不用現在就把地圖做大。

## 風險與取捨

- **超市原本是「門開在面向商業街的後牆」**，搬走後這個連接就沒了。改成在原位置畫超市門面，門口就是進入室內的地方。
- **一個場景分在兩處**，「目前街區」的鏡頭和提示要改成看部分。看圖找的提示（區域高亮）要先移到那個區域所在的部分，不然會指向畫面外。
- **戶外地塊的「車道」地形**（醫院、學校門口）會和大街重複。先保留，之後看預覽圖再決定要不要改成直接面向大街。
- **物件的絕對位置會變**（區域內的相對位置不變）。目前沒有外部玩家，影響有限。
- **工時**：我估計實作大約是半天到一天，但沒做過類似的搬遷，這只是推測；最不確定的是步驟 2 的背景和步驟 3 的鏡頭。

## 實作結果（2026-09-23）

和上面的規劃不同的地方：

- **不用停排程**：改動在另一個分支，只有合併的那幾分鐘要避開排程（持有 `.auto-expand/lock`）。
- **沒有 `content/town-plan.json`**：位置直接寫在各街區規劃的 `rects`，已用的地塊與建築從 scene-config 算（`townOccupancy`）。搬遷腳本是 `scripts/migrate-town.mjs`。
- **地塊實際配置**：原本超市那塊改成「超市門面 + 停車場」，沒有放地塊；西邊的地塊列在 y 2700（車站前廣場、月台）。東區 4 列 × 4 欄，加上西邊 2 塊，共 18 塊，目前用 12 塊。
- **室內區**：從 y 3700 開始，寬 8600，目前 5 列；地圖變成 8900 × 7960。
- **鏡頭**：原本就是跳到區域中心（提示、導覽列、切換街區），不用另外改；未解鎖的鎖頭與說明改成每一部分各畫一個。

**已知問題**：醫院、機場、消防局的門口地塊裡本來就有一條車道，下面又接大街，看起來像兩條平行的路（見「風險與取捨」第 3 點）。
